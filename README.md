# 文档分发助手（doc-mailer）

面向任何"给一批外部收件人分发机密文件"场景的一站式工具：**给每位收件人生成专属水印加密 PDF，并自动创建 Outlook 草稿**（只建草稿、绝不自动发送）。适用客户交付、股东/投资人函件、合作方资料分发等。

## 功能特性

- **逐收件人独立防护**：每位收件人独立水印文字 + 独立打开口令 + 独立权限口令（AES-256；允许打印，禁止修改 / 复制 / 批注 / 拼装），泄露可溯源
- **水印自适应**：名称过长自动换行或缩小字号，不截断；可选单份 / 三份（防裁剪）/ 平铺 2×3；字体、字号、颜色、角度均可调，弹窗内即时预览
- **收件人清单管理**：Excel(xlsx)/CSV 批量导入（按表头名识别列）、收件人/抄送/密送、每人专属邮件标题与预制附件（多个用 `;` 分隔）、「检查附件」一键核对就绪、口令留空自动生成、多选批量删除
- **邮件模板**：标题 + HTML 正文，`{{收件人名称}}` `{{水印名称}}` `{{打开口令}}` `{{日期}}` 字段批量替换（旧 `{{LP名称}}` 兼容）；所见即所得编辑器支持富文本粘贴（Word / 网页样式保留）与格式工具栏，右侧实时预览
- **Outlook 草稿**：逐收件人建草稿（加密文件 + 预制附件自动挂上），只 `Save` 不 `Send`——发送永远需要人工复核；不选原件也可仅按清单建草稿
- **权限口令隔离**：模板字段中没有权限口令，权限口令从产品层面无法进入邮件
- **输出自定义**：文件名模板（`{{原件名}} {{收件人名称}} {{水印名称}} {{日期}}`）、输出目录记忆

## 下载（免安装）

到 [Releases](../../releases) 页面：

| 包 | 适用 |
|---|---|
| `LP_Tool_portable.zip` | **推荐**：绿色免安装（解压双击 bat 即用，通常无安全软件拦截） |
| `LP_Tool_win64_signed.zip` | 签名版 exe（内附证书与导入说明，适合受管控电脑） |
| `LP_Tool_win64.zip` | 云端构建的未签名版 |

Windows 10/11 x64，无需安装 Python 或任何依赖。首次运行自动载入演示数据；
Outlook 草稿功能需本机安装 Outlook 并配置账户（未安装时"仅生成加密文件"仍可用）。

## 快速上手（5 分钟）

1. ① 收件人管理 →「导入 Excel/CSV」→ 选 `examples/收件人清单示例（演示数据）.xlsx`
2. ② 邮件模板 → 编辑正文，右侧实时预览
3. ③ 生成文件 / Outlook 草稿 → 添加原件 PDF →「生成加密文件 + Outlook草稿」
4. 打开 Outlook 草稿箱逐封复核后手动发送

详细说明见 `docs/使用说明.txt`。

## 示例数据

`examples/` 下的公司名、邮箱（保留域名）、口令均为**虚构演示数据**：
- `收件人清单示例（演示数据）.xlsx` — 8 条演示收件人，覆盖超长名称等边界情况
- `收件人清单导入模板.xlsx` — 空白导入模板，表头即识别依据
- `lp_data.example.json` — 程序首次运行的种子数据（复制到程序旁生效）
- `演示原件.pdf` — 2 页模拟文件，用于测试全流程
- `水印效果对比.png` — 三种水印模式效果对比

## 安全须知

- 程序旁的 `lp_data.json` 保存全部收件人信息与**权限口令**，属敏感文件，请勿外发、勿提交到仓库（已在 `.gitignore` 排除）
- 权限位由阅读器（Acrobat / Edge / WPS 等）强制执行；持有打开口令者理论上可借助工具破解，这是 PDF 标准的固有边界
- 发给收件人的只有：加密文件 + 打开口令

## 从源码运行

```bash
pip install -r requirements.txt
python src/lp_tool.py
```

打包 exe：`pip install pyinstaller && pyinstaller --onefile --noconsole --name LP_Tool src/lp_tool.py`

## 目录结构

```

├── examples/            # 演示数据与导入模板
├── docs/                # 使用说明
├── signing/             # 自签名证书公钥与导入说明
└── .github/workflows/   # 打 tag 自动构建 exe 并发布 Release
```

发布新版本：`git tag v0.x && git push --tags`，Action 自动打包 exe 上传到 Releases。
