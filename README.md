# 文档分发助手（doc-mailer）

面向任何"给一批外部收件人分发机密文件"场景的一站式工具：**给每位收件人生成专属水印加密 PDF，并自动创建 Outlook 草稿**（只建草稿、绝不自动发送）。适用客户交付、股东/投资人函件、合作方资料分发等。

## 功能特性

- **逐收件人独立防护**：每位收件人独立水印文字 + 独立打开口令 + 独立权限口令（AES-256；允许打印，禁止修改 / 复制 / 批注 / 拼装），泄露可溯源
- **水印自适应**：名称过长自动换行或缩小字号，不截断；可选单份 / 三份（防裁剪）/ 平铺 2×3；字体、字号、颜色、角度均可调，弹窗内即时预览
- **收件人与事件**：Excel/CSV 批量导入本次名单和业务字段；收件人库维护长期联系人和标签，支持按标签批量加入事件。打开口令与权限口令留空可自动生成
- **四种文件入口**：Word MailMerge 生成专属文档、PDF 水印加密、非 PDF 可选转 PDF 后处理、Excel 按 LP 对应已有文件；每个 Excel 条目独立保存对应关系，支持自定义最终附件清单
- **邮件模板**：主题 + HTML 正文，内置和本事件字段批量替换；紧凑编辑工具栏支持字体、字号、颜色、对齐、图片、字段和富文本粘贴。总览可逐封编辑并保存
- **Outlook 草稿**：逐收件人或合并组创建草稿并附上处理好的文件，只 `Save` 不 `Send`；发送前由使用者人工复核
- **权限口令隔离**：模板字段中没有权限口令，权限口令从产品层面无法进入邮件
- **输出自定义**：文件名模板（`{{原件名}} {{收件人名称}} {{水印名称}} {{日期}}`）、输出目录记忆
- **配置兼容升级**：识别失效的旧产物覆盖和隐藏附件，先备份再升级；无法安全转换的设置明确提示并停止覆盖
- **更新进度**：便携版自动更新显示下载、校验、解压和安装进度，可取消下载；安装前备份程序与配置，保留用户数据

## 下载（免安装）

到 [Releases](../../releases) 页面：

| 包 | 适用 |
|---|---|
| `doc-mailer_v版本号_portable.zip` | 便携版，解压后启动 `app/start.bat`，内置 Python 运行环境 |
| `doc-mailer_win64.zip` | 本机签名的 exe，解压后运行 `LP_Tool.exe` |

Windows 10/11 x64，无需安装 Python 或任何依赖。首次运行自动载入演示数据；
Outlook 草稿功能需本机安装支持 COM 的桌面 Outlook 并配置账户；Word 合并及文档转 PDF 需安装相应的 Microsoft Office，图片转 PDF 无需 Office。

## 快速上手（5 分钟）

1. 事件 → 新建事件；在「收件人」导入 Excel/CSV 或从收件人库按标签选择
2. 「文档流水线」选择四种入口，配置文件和处理选项，点击「处理并下一步」
3. 「邮件模板」编辑统一主题与正文，点击「预生成并下一步」；未保存时先确认保存
4. 「总览」逐封核对邮件及附件，保存单封修改后生成 Outlook 草稿
5. 打开 Outlook 草稿箱复核后手动发送

详细说明见 `docs/使用说明.txt`。

## 示例数据

`examples/` 下的公司名、邮箱（保留域名）、口令均为**虚构演示数据**：
- `收件人清单示例（演示数据）.xlsx` — 8 条演示收件人，覆盖超长名称等边界情况
- `收件人清单导入模板.xlsx` — 空白导入模板，表头即识别依据
- `lp_data.example.json` — 程序首次运行的种子数据（复制到程序旁生效）
- `演示原件.pdf` — 2 页模拟文件，用于测试全流程
- `水印效果对比.png` — 三种水印模式效果对比

## 安全须知

- 程序旁的 `lp_data/` 保存事件、联系人、口令及执行历史，属敏感数据，请勿外发或提交到仓库（已在 `.gitignore` 排除）。升级时保留该目录；旧事件首次保存为新版流水线前会自动备份
- 权限位由阅读器（Acrobat / Edge / WPS 等）强制执行；持有打开口令者理论上可借助工具破解，这是 PDF 标准的固有边界
- 发给收件人的只有：加密文件 + 打开口令

## 从源码运行

```bash
pip install -r requirements.txt
python src/lp_tool.py
```

打包 exe：`pip install pyinstaller && pyinstaller --onefile --noconsole --name LP_Tool src/lp_tool.py`

## 目录结构

```
├── src/                 # 源码（lp_tool.py 主程序 / watermark_encrypt.py 核心逻辑）
├── examples/            # 演示数据与导入模板
├── docs/                # 使用说明
├── signing/             # 自签名证书公钥与导入说明
└── .github/workflows/   # 打 tag 自动构建 exe 并发布 Release
```

发布新版本：`git tag v0.x && git push --tags`，Action 自动打包 exe 上传到 Releases。
