文档分发助手 — 快速上手
================================

给一批发件对象（客户/合作方/股东/投资人……任何外部收件人）批量分发文件：
每人一份专属水印 + 专属打开口令 + 专属权限口令的加密 PDF，
并自动生成 Outlook 草稿（只建草稿、不自动发送，人工复核后再发）。

一、包内文件
  主程序（绿色版双击「启动」bat，exe 版双击 exe）
  收件人清单示例（演示数据）.xlsx  8 条虚构数据，导入即可体验全流程
  收件人清单导入模板.xlsx          空白导入模板（表头即识别依据，可自行增删列）
  演示原件.pdf                    2 页模拟文件，用作流程测试的"原件"
  水印效果对比.png                单份 / 三份（防裁剪）/ 平铺 2×3 效果对比

二、五分钟跑通演示流程
  1. 启动程序（若 exe 弹安全提示：更多信息 → 仍要运行；
     若程序旁有 lp_data.example.json，首次启动自动载入 8 条演示数据）
  2. ①页 →「导入 Excel/CSV」→ 选示例清单（口令留空的已自动生成）
  3. ②页即所见即所得编辑器：从 Word/网页复制后 Ctrl+V 自动保留样式，
     工具栏可 B/I/U、字号、文字色、高亮、居中、插字段；右侧预览实时刷新，
     中缝可拖动调整宽度；「保存模板」写回、「导入HTML文件…」可导入正文
  4. ③页 →「添加原件PDF」选演示原件 → 需要时点「水印设置…」调整 →
     点「生成加密文件 + Outlook草稿」（不选原件也可仅按收件人清单建草稿）
  5. 打开 Outlook 草稿箱逐封复核，确认无误后手动发送

三、字段与口令
  · 可用字段：{{收件人名称}} {{水印名称}} {{打开口令}} {{日期}}
    （旧模板的 {{LP名称}} 仍兼容）没有权限口令字段——权限口令永远不进邮件
  · 每份文件 = 独立水印 + 独立打开口令 + 独立权限口令（AES-256；
    允许打印，禁止修改/复制/批注/拼装）
  · ①页支持：密送(BCC)、附件路径（预制文件多个用;分隔）、「检查附件」
    一键核对文件是否就绪、Ctrl/Shift 多选批量删除
  · 自动更新：③页可检查 GitHub 新版；绿色版确认后自动下载→SHA256校验→
    保留数据替换→重启（lp_data.json/审计日志/备份 全部保留不动）

四、安全要点
  · 程序只创建 Outlook 草稿，绝不自动发送；发送必须人工复核
  · 程序同目录的 lp_data.json 含全部权限口令，属敏感文件：
    目录不要放公开位置，不要连同 json 一起外发
  · 给收件人的只有：加密文件 + 打开口令

五、常见问题
  · 双击被拦截：SmartScreen 点"仍要运行"；或 powershell 执行
    Get-ChildItem | Unblock-File；绿色版通常无此问题
  · 草稿失败：确认本机 Outlook 已安装并配置好账户
  · 水印可自定义：③页「水印设置…」可选布局（自动/强制单行/强制折行）、字体、
    最大字号、颜色、角度、份数（单个/三份/平铺2×3），弹窗内即时预览
  · 输出目录默认 文档\文档分发输出（记住上次选择）；文件名模板可自定义，
    字段：{{原件名}} {{收件人名称}} {{水印名称}} {{日期}}
  · 附件缺失的预制文件会在生成草稿时跳过并记入日志

—— 演示数据均为虚构，邮箱使用保留域名，不会发往真实地址
