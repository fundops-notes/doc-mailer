文档分发助手 v3.9.1 — 快速上手
================================

给一批外部收件人（客户 / 合作方 / 投资人……）批量分发文件：
每人一份专属水印 + 专属打开口令 + 专属权限口令的加密文件，
并生成 Outlook 草稿（只建草稿、不自动发送，人工复核后再发）。

一、包内文件
  LP_Tool.exe                主程序，双击运行
  lp_data.example.json       演示数据（8 条虚构收件人），
                             首次启动自动载入，想从零开始可在「设置」里清掉
  使用说明.txt               本文件

二、界面结构
  左侧导航按业务分组：
    · 工作台：事件 / 收件人库 / 执行历史（三者并列，点击直接切换）
    · 系统：设置 / 帮助
  侧栏底部的版本号旁是「检查更新」；顶栏显示当前位置和事件操作。
  功能分工：事件列表管理事件及备份；事件工作台维护本次名单和业务字段；
  收件人库维护可复用联系人和标签。事件首页不再重复放收件人导入/导出按钮。
  跨事件明细在「更多导出… → 导出各事件收件人明细…」，按事件分别列出，
  同一联系人可出现多行；各事件业务字段按统一列名对齐。
  整体为 Modern Enterprise SaaS 风格：浅灰背景、白色内容面、蓝色主操作、细边框
  首页不再有页内标签栏；事件 / 收件人库 / 执行历史 都在左侧「工作台」下
  事件库里一个「事件」= 一次分发。新建后进入工作台，固定四步：

     ① 收件人      谁收、多少人、发几封（每人一份 / 按组合并 / 全部合并）
                   表格里没有「附件路径」列，「下载导入模板」里也没有；
                   导入 Excel 时日期/金额/百分比按 Excel 里显示的格式读取；
                   日期列默认按 Excel 里显示的文本导入；如果日期列是
                   General 格式的数字（如 46193），导入时会弹窗让你选择：
                   保持 Excel 显示文本 / 转成 2026-06-20 / 2026年06月20日 / 2026/06/20。
                   想要不同的日期展示，先在 Excel 里把列格式设置成需要的样式，
                   再导入即可保留该显示文本；
                   导入时文件里若带了这一列，只当自定义字段收进来，不进附件包
                   列：收件人名称、To、CC、BCC、水印、组、
                   打开口令、权限口令(勿发，显示 ••••)
                   自定义字段不在收件人表/编辑框里显示：由「导入 Excel/CSV」
                   或 Word-MailMerge 的「导入要素模板」带入，只用于文档映射
                   工具条有本事件导入/导出、增删改、收件人库往返
                   「从收件人库添加…」弹窗可按标签筛选；选择标签后点
                   「全选当前列表」批量选人，再点「添加」加入当前事件。
                   支持全部收件人/未打标签，显示标签与已选人数；切换标签
                   会清空选择，避免隐藏项误加；同名合并保留已有口令。
     ② 文档流水线  四种入口分别配置（见三）；点击底部「处理并下一步」先保存
                   最新设置并处理文件，成功后进入邮件模板；失败留在本页查看日志
     ③ 邮件模板    统一的主题与正文；编辑器就是所见即所得；
                   可设字体、字号、文字色、背景色、左/中/右对齐，插图片与字段；
                   点击底部「预生成并下一步」进入总览；有未保存修改时先提示
                   保存后继续，取消则留在本页（预生成会清空总览里之前的单封手改）
     ④ 总览        左侧邮件清单（收件人 / 合并组），点一行右侧是编辑器：
                   可对这一封邮件单独改内容/样式，点「保存这封邮件」存档；
                   下方附件可点文件名直接打开；确认后生成全部 Outlook 草稿
                   （生成时会使用你保存的单封修改）

  窗口变窄时，工作台四步会改为顶部排列；工具栏按钮按可用宽度自动换行。
  窗口高度不足时，可使用页面右侧滚动条。流水线左侧参数区、右侧处理区
  另有独立竖向滚动条；加密权限与字段映射在参数区下方，向下滚动即可查看。
  鼠标滚轮只作用于所在区域，Tab切换焦点会自动显示对应控件。
  条目表、字段映射、总览清单及路径文本框支持横向滚动，长路径可以完整查看。

  页面底部有「上一步 / 下一步」推进按钮；点击后续步骤也会执行相应处理。
  从流水线前进会先保存并完成处理，从邮件模板前进会保存并预生成。
  邮件模板或单封邮件有未保存修改时，跳转页面或生成草稿会强提醒：
  选择保存则先保存并刷新，不保存则放弃，取消则留在当前页。

二之二、收件人库（跨事件复用）
  常用的一批收件人放左侧「收件人库」，新建事件时直接挑人。
  工具条：新增 / 编辑 / 标签… / 删除 / 从事件导入… /
          添加到事件… / 导入联系人 Excel/CSV / 导出联系人 Excel / 下载联系人模板
  自定义字段属于「事件」而不是收件人本身：收件人库不保存、不显示事件里的
  自定义字段（如 Call_Amount），避免多个事件用过的字段越积越多。
  旧版本遗留在库里的历史字段不会再显示；从事件存入/导入到库也不会带字段。
  库的联系人模板和导出文件带「标签」列，导入支持多标签（分号/逗号/换行分隔）。
  同名联系人只补空缺资料，已有邮箱与口令保留，标签取并集；空白标签不清空旧标签。
  导入后会保存同名合并的结果；Excel 导出再导入可以保留标签。
  本次金额、截止日期等业务字段请在事件工作台导入，库导入预览会提示忽略这些列。
  标签：可在「标签…」里给选中的多位收件人批量加标签；批量移除只能移除
  大家共有的标签，只属于部分人的特异标签不会被批量移除，避免误删。
  「从事件导入…」导入完成后会提示给这批收件人打标签。
  合并规则（重要）：按「收件人名称」匹配；已有的项只补空缺（邮箱、抄送、
  密送、水印、组、标题）；**目标里已有的打开口令与权限口令
  永远不会被覆盖**。库和事件不会自动同步，改动都要显式点按钮。
  库里也存着口令（表里显示 ••••），与 lp_data/ 同管控级别（见六）。

二之三、执行历史
  左侧「执行历史」页面。每生成一次草稿就留一条记录：
  开始时间、事件、状态、草稿数、成功/失败/跳过人数、附件包数。
  双击一行看详情：每位收件人拿到了几个文件、哪些文件缺失、有没有出错、
  草稿名，以及这一次的执行日志与提醒。
  执行记录是审计材料，这里只看不删。

三、文档流水线：左右分栏
  左栏 = 条目表 + 选中条目的参数区
  右栏 = 收件人↔文件对应表 + 实时处理日志

  每一行 = 一个产出条目，四种入口并列：
     Word MailMerge   用 Word 模板，给每位收件人生成内容不同的文档
     PDF 文件         添加已有 PDF，可选加水印、加密；不处理则附加原内容
     非 PDF 文件      添加已有文件，可选转 PDF 后加水印、加密；不勾选则保留原格式
     Excel 按 LP 匹配 导入「收件人名称 + 附件路径」两列，按 LP 取自己的文件；
                      每条独立保存对应关系，可以同时导入多批不同的文件清单
  「转 PDF / 加水印 / 加密」不是单独一行，而是条目上的勾选项，
  顺序固定（转 PDF → 加水印 → 加密）；水印与加密只对 PDF 生效，
  Word 和非 PDF 条目想加就先勾「转成 PDF」。
  支持 Word、Excel、PowerPoint、常见图片和文本/HTML 转 PDF；
  文档转换需要本机安装相应的 Microsoft Office，图片转换无需 Office。
  不支持转换的格式可不勾选处理，按原格式附加。

  Word-MailMerge 参数区：模板路径、「选择…」「检测占位符」；
  「生成文件名模板」——这一条生成任务统一使用的文件名（留空用默认
  `{{原件名}}_{{LP名称}}`），可用 {{原件名}} {{LP名称}} {{水印名称}} {{日期}}；
  占位符写法、处理顺序（转 PDF → 水印 → 加密）、水印/口令维护位置
  直接写在参数区里（不再有「说明」弹窗）。按钮：
     「导出要素模板」        列 = 占位符，行 = 本事件收件人，值按映射预填
     「导入要素模板」        把填好的模板导回来：按收件人名称匹配，值写进
                            收件人字段，并自动把占位符接到对应字段来源
     「下载示例 Word 模板」  生成一份含 6 个占位符的示例 .docx，可直接试
  邮件编辑器：字体、字号、文字色、背景色、左/中/右对齐、插入图片、
  插入字段、清除格式；插入的图片会直接显示在编辑器里，
  并在生成 Outlook 草稿时转成内嵌图片。
  PDF / 非 PDF 参数区：「添加 PDF… / 添加文件…」「保存文件清单」；
     文件清单适用于本事件收件人，加水印/加密时按各人的设置产出。
  Excel 参数区：「导入对应清单…」「导出对应模板」和对应关系表；
     同一 LP 可有多行，或在一格用分号分隔多个路径；相对路径以清单所在目录为准。
     按收件人名称精确匹配，未匹配名称会提示；不修改收件人库或其它条目的对应关系。
     可选转 PDF、加水印、加密，处理规则与文件入口一致。

  加密勾选后出现「发送人统一密码」：勾上并填口令，所有文件的权限口令
  都用这一个（方便发送人自己打开核对）；口令随当前事件保存，不影响其它事件。
  收件人仍用各自打开口令。

  「处理并下一步」按最新参数生成文件，不建 Outlook 草稿；
  保存的自定义对应优先作为最终附件清单，其余收件人按流水线生成。
  处理完成后更新对应表并进入邮件模板；保存失败、缺文件或处理失败不会前进。
  对应表：双击「将收到的文件」/「文件路径」可编辑完整路径，点「保存自定义对应」
  写回事件；点击下一步也会提交当前编辑。选中后点「恢复选中自动对应」可取消覆盖。
  生成草稿会复用已处理的文件；处理参数、来源文件或名单变化时会重新核对处理。

  所有附件统一从四种流水线条目进入，也可使用已保存的自定义对应。
  原来的「统一附件」入口已移除；打开旧事件时，原有统一附件会显示为独立条目，
  保留原文件名和适用范围；首次保存前自动备份旧事件到 lp_data/backups/。
  旧事件的收件人附件和字段/外部表取路径方式继续兼容，不批量改写历史数据。

  表格操作：单击行→左侧参数区；按住行上下拖动→改顺序；
  Ctrl/Shift 多选→批量删除；双击条目行→光标跳到左侧「名称」框
  （直接在名称框里改，点「改名」或按回车立即生效，不弹对话框）；
  点「启用」列→暂不产出；条目表下方有横向滚动条。

  产出方式固定按分组：同一合并组共用一份文件，未分组的收件人各自一份。
  「产出颗粒度」设置已取消；邮件分组在「收件人」页的「组」列维护。

四、字段来源（映射表）
  在 Word 模板里写占位符，两种写法都支持：{{字段名}}  或  ?字段名?
  在流水线条目的「字段映射」里，每个占位符单独选一个具体来源，
  表格里直接显示预览值（以第一位收件人为例），当场就能看懂会填成什么：

     收件人名称 / 水印名称 / 打开口令 / 日期     内置
     本事件字段    从 Excel/CSV 或「导入要素模板」带进来的数据列
                    （不在收件人表里显示，避免字段越积越多）
     事件常量      事件选项里定义的固定值
     外部数据表    从 Excel 按收件人匹配进来的列

  双击映射表某一行 → 弹出「占位符来源」：
    上方下拉可以切换本条目里的**所有**占位符（默认选中你双击的那一行），
    下方选这个占位符的数据来源，点「确定」保存。
  没有「权限口令」字段 —— 权限口令按规则永远不进文档或邮件。

五、加密权限
  勾了「加密」的条目可以设置权限：允许打印 / 允许编辑 / 允许复制内容。
  默认只勾「允许打印」（与旧版行为一致）；全部取消 = 收件人只能打开查看。
  打开口令取每位收件人自己的打开口令，权限口令由系统保管；
  勾了「发送人统一密码」时，权限口令统一用设置里那一个。

六、安全要点
  · 程序只创建 Outlook 草稿，绝不自动发送；发送必须人工复核
  · 每份文件 = 独立水印 + 独立打开口令 + 独立权限口令（AES-256）
  · 数据保存在程序目录下的 lp_data/ 文件夹里，含全部权限口令与
    「发送人统一密码」，属敏感文件：
    这个目录不要放在公开位置，也不要整个外发。备份直接拷这个目录即可。
  · 给收件人的只有：加密文件 + 打开口令

七、常见问题
  · 双击被拦截：SmartScreen 点「仍要运行」
  · 草稿失败：确认本机 Outlook 已安装并配置好账户
  · 水印可自定义：设置页「水印设置…」可选布局、字体、最大字号、颜色、角度、
    份数（单个 / 三份防裁剪 / 平铺 2×3），弹窗内即时预览
  · 输出目录默认程序所在目录；可在设置里更改，文件名模板在 Word-MailMerge 条目内维护
  · 附件缺失会在生成时跳过并记入日志，不会中断整批
  · 自动更新：左侧底部版本号旁「检查更新」；确认后自动下载 →
    SHA256 校验 → 保留数据替换 → 重启（lp_data/ 全部保留不动）
  · 自动更新失败？v3.4.9 修复了下载进度回调的参数签名（旧版点「自动更新」
    会报 `_prog() takes 1 positional argument but 3 were given`）。
    若仍失败，按弹窗提示到 Releases 页手动下载覆盖即可。
  · 「检查更新」提示连接失败？v3.4.7 起先走 github.com 网页跳转取版本号，
    不再依赖 GitHub API 的匿名额度（该额度按出口 IP 限 60 次/小时，走代理时
    很容易被共享 IP 用尽而返回 403）。若仍失败，弹窗会给出「网页跳转 / API」
    两种方式的具体原因，可直接打开 Releases 页面手动下载。
