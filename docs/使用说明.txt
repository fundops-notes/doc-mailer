文档分发助手 v3.3.0 — 快速上手
================================

给一批外部收件人（客户 / 合作方 / 投资人……）批量分发文件：
每人一份专属水印 + 专属打开口令 + 专属权限口令的加密文件，
并生成 Outlook 草稿（只建草稿、不自动发送，人工复核后再发）。

一、包内文件
  LP_Tool.exe                主程序，双击运行
  lp_data.example.json       演示数据（8 条虚构收件人），
                             首次启动自动载入，想从零开始可在「设置」里清掉
  使用说明.txt               本文件

二、界面结构
  左侧三个入口：事件库 / 设置 / 帮助
  事件库里有四个标签页：事件 / 场景模板 / 收件人库 / 执行历史
  事件库里一个「事件」= 一次分发。新建事件后进入工作台，固定六步：

     ① 收件人      谁收、多少人、发几封
                   （发送模式：每人一份 / 按组合并 / 全部合并）
                   表格里有一列「附件路径」：这一位专属要附的文件，
                   导入清单里的同名列会进这里，文件不存在时标红
                   工具条上有「从收件人库添加…」与「存入收件人库」
     ② 文档流水线  一张表，每一行 = 一个要附上的东西
     ③ 附件        不想走流水线时的快捷挂载
     ④ 邮件模板    主题与正文
     ⑤ 总览        生成前逐人核对最终附件包与邮件样子
     ⑥ 预览与生成  预检 → 生成 Outlook 草稿

二之二、收件人库（跨事件复用）
  「事件库 → 收件人库」标签页。常用的一批收件人放这里，
  以后新建事件时直接挑人，不用每次重新导表。

  工具条：
     新增 / 编辑 / 删除
     从事件导入…    把某个事件的收件人整个收进库
     添加到事件…    把库里选中的人并进某个事件
     导入 Excel/CSV  按收件人清单模板导入
     导出 Excel      把整个库导出成 Excel
     下载导入模板    拿一份空白模板（含填写说明页）

  合并规则（重要）：
     按「收件人名称」匹配；已有的项只补空缺（邮箱、抄送、密送、水印、组、
     标题、附件路径、自定义字段）；**目标里已有的打开口令与权限口令
     永远不会被覆盖**。库和事件都不会自动同步，改动都要显式点按钮。

  库里也存着口令，与 lp_data/ 其余部分同管控级别（见「六、安全要点」）。

二之三、执行历史
  「事件库 → 执行历史」标签页。每生成一次草稿就留一条记录：
  开始时间、事件、状态、草稿数、成功/失败/跳过人数、附件包数。
  双击一行看详情：每位收件人拿到了几个文件、哪些文件缺失、有没有出错、
  草稿名，以及这一次的执行日志与提醒。
  执行记录是审计材料，这里只看不删。

三、文档流水线：表格怎么用
  每一行 = 一个产出条目，只有两种：

     生成文档   用一个 Word 模板，给每位收件人生成一份内容不同的文档
     附加文件   把磁盘上已有的文件放进附件包
                （可手填路径，一行一个；也可「从 Excel 导入路径…」批量灌入）

  「转成 PDF / 加水印 / 加密」不是单独一行，而是条目上的勾选项，
  顺序固定（转 PDF → 加水印 → 加密），不用自己去排。

  附加文件条目的「路径来源」= 文件路径从哪来：
     手填路径                  下面这份清单，所有收件人一样（默认）
     收件人清单的「附件路径」列  每人取自己那一列
     收件人字段 / 外部数据表列   从对应的那一列按收件人取值
  选了按人取之后，某个人没取到路径只是跳过，不会让整批失败。

  每个人的附件一共来自三处：
     收件人页的「附件路径」列   这一位专属要附的文件（导入模板里的同名列进这里）
     流水线的「附加文件」条目   见上面的「路径来源」
     「附件」页                 事件级静态文件（全部 / 指定收件人 / 按合并组）

  表格操作：
     单击一行          → 下方显示该条目的参数
     按住行上下拖动    → 调整顺序（顺序 = 附件在邮件里的排列）
     Ctrl / Shift 多选 → 「删除选中」批量删除
     双击「条目名称」  → 改名
     点「启用」列      → 这一条暂不产出（后面的条目照常执行）

  「产出粒度」= 这一条产出几份文件：每人一份 / 每组合并一份 / 全员共用一份。
  它和事件级的「发送模式」不是一回事：发送模式决定几封邮件，
  产出粒度决定这一条产出几份文件。

四、字段来源（映射表）
  在 Word 模板里写占位符，两种写法都支持：{{字段名}}  或  ?字段名?
  在流水线条目的「字段映射」里，每个占位符单独选一个具体来源，
  表格里直接显示预览值（以第一位收件人为例），当场就能看懂会填成什么：

     收件人名称 / 水印名称 / 打开口令 / 日期     内置
     收件人字段    收件人表里你自己加的列（可临时加列）
     事件常量      事件选项里定义的固定值
     外部数据表    从 Excel 按收件人匹配进来的列

  没有「权限口令」字段 —— 权限口令按规则永远不进文档或邮件。

五、加密权限
  勾了「加密」的条目可以设置权限：允许打印 / 允许编辑 / 允许复制内容。
  默认只勾「允许打印」（与旧版行为一致）；全部取消 = 收件人只能打开查看。
  打开口令取每位收件人自己的打开口令，权限口令由系统保管。

六、安全要点
  · 程序只创建 Outlook 草稿，绝不自动发送；发送必须人工复核
  · 每份文件 = 独立水印 + 独立打开口令 + 独立权限口令（AES-256）
  · 数据保存在程序目录下的 lp_data/ 文件夹里，含全部权限口令，属敏感文件：
    这个目录不要放在公开位置，也不要整个外发。备份直接拷这个目录即可。
  · 给收件人的只有：加密文件 + 打开口令

七、常见问题
  · 双击被拦截：SmartScreen 点「仍要运行」
  · 草稿失败：确认本机 Outlook 已安装并配置好账户
  · 水印可自定义：设置页「水印设置…」可选布局、字体、最大字号、颜色、角度、
    份数（单个 / 三份防裁剪 / 平铺 2×3），弹窗内即时预览
  · 输出目录默认 文档\文档分发输出（会记住上次选择）；文件名模板可自定义
  · 附件缺失会在生成时跳过并记入日志，不会中断整批
  · 自动更新：事件库右上角「检查更新」；确认后自动下载 →
    SHA256 校验 → 保留数据替换 → 重启（lp_data/ 全部保留不动）

—— 演示数据均为虚构，邮箱使用保留域名，不会发往真实地址
